# Controls

## Desktop (mouse and keyboard)

Click the game once to capture the mouse (pointer lock). If the browser refuses pointer lock,
the game switches to cursor mode: aim with the cursor and hold the right mouse button to look.

| Action | Default |
| --- | --- |
| Move / hurry | W A S D (arrow keys also work) · Shift |
| Crouch (reach low shelves) | Ctrl or C |
| Look | Mouse (arrow keys left/right for keyboard look) |
| Pick up | Hold left mouse on an item, release on a surface to place (or enable *Toggle to hold*) |
| Take from a bin or the chiller drawer | Click the ingredient |
| Turn a grill knob / pull the drawer | Click and drag it |
| Rotate held item | Hold right mouse and move |
| Hold closer / farther | Mouse wheel |
| Contextual use: flip with spatula, hand an item to a teammate, flip the OPEN sign | E |
| Set down safely | Q |
| Inspect (doneness, temperature, sauces) | Hold F |
| Recipe book | R |
| Ping teammates | T, then 1–6 |
| Toggle ticket overlay | Tab |
| Menu, settings, pause | Esc |

All keys are remappable in *Settings → Keys*. *Simple interactions* makes knobs and the drawer
step on click instead of dragging.

### Cooking moves

- **Spatula:** pick it up, click a patty/bun/bacon/egg/mushrooms to slide under it, then press
  E to flip it back onto the grill, or click a burger/tray/counter to put it there. E while
  aiming at a patty does a quick flip in one move.
- **Sauce:** pick up a bottle (ketchup, mustard, mayo, BBQ, house) and hold click on the burger.
- **Serve:** tray with a closed burger (top bun last) onto the pickup shelf under the heat lamp.

## iPad / touch

A short tutorial appears the first time. No keyboard, mouse, Pencil or home-screen install is
needed.

| Action | Touch |
| --- | --- |
| Move | Left thumb stick (push fully to hurry) |
| Look | Drag anywhere else on the screen |
| Pick up / place | Tap the item, then tap where it goes (lifting a finger never drops anything) |
| Knob / drawer | Drag it directly |
| Spatula flip | Tap a patty to slide under, then swipe up or press **Use** |
| Squeeze sauce | Press and hold on the burger with a bottle in hand |
| Hold closer / farther | Pinch, or the **Near** / **Far** buttons |
| Rotate held item | **Rotate** toggle, then drag |
| Crouch, Inspect, Set down, Ping, Recipes, Menu | On-screen buttons |

*Settings → Touch* changes control size and swaps the stick to the right side. Rotation and
resizing keep the session; backgrounding clears held input and reconnects on return.
