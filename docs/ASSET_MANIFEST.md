# Asset manifest

Every model, texture, lightmap, reflection probe and graphic in the game is generated by code
in this repository (see `docs/ASSET_PIPELINE.md`). There are no third-party models, scanned
textures, stock photos or sound files. Built outputs live under `apps/client/public/assets/`
and are covered by the project licence (Apache-2.0) unless noted.

Build tools (not shipped): Blender's `bpy` module (GPL; Blender's licence places no
restrictions on files you create with it), Intel Open Image Denoise via `pyoidn` (Apache-2.0),
NumPy/SciPy/scikit-image (BSD), Pillow (HPND), Babylon.js (Apache-2.0) for `.env` conversion.

Stand-in meshes created by the client when authored assets are unavailable carry
`metadata.placeholder = true`; once the authored versions load they are hidden (or replaced),
so a running scene can be audited for remaining placeholders.
